# GOOD ENOUGH™ Market Program - SMS Campaign Templates

## OVERVIEW

This document provides standardized SMS templates for market franchisees to maintain brand voice while effectively communicating with customers. All messages should be personalized where indicated and sent through the approved GOOD ENOUGH™ SMS platform.

## GENERAL GUIDELINES

- Keep messages under 160 characters when possible
- Use minimal emoji (maximum 1 per message)
- Always include location details
- Maintain understated, confident tone
- Never use exclamation points
- Include opt-out information in initial messages
- Send messages between 5-7pm local time on Fridays

## WEEKLY DROP ANNOUNCEMENT

### Standard Template

```
GOOD ENOUGH at [MARKET NAME]: This Saturday. [PRODUCT HIGHLIGHT] in [COLOR]. Limited quantities. Early access 8:45am. Reply STOP to unsubscribe.
```

### Example
```
GOOD ENOUGH at West Loop Market: This Saturday. Heavy Tee in Smoke. Limited quantities. Early access 8:45am. Reply STOP to unsubscribe.
```

### Premium Drop Template

```
GOOD ENOUGH [CITY] presents [PREMIUM PRODUCT] in [COLOR/MATERIAL]. [MARKET NAME], this Saturday. Very limited. Early access 8:45am.
```

### Example
```
GOOD ENOUGH Chicago presents Hand-Dyed Work Jacket in Indigo. West Loop Market, this Saturday. Very limited. Early access 8:45am.
```

## SPECIAL ANNOUNCEMENTS

### Collaboration Drop

```
GOOD ENOUGH × [COLLABORATOR]: [PRODUCT]. [MARKET NAME] this Saturday only. [UNIQUE DETAIL]. Limited edition of [NUMBER].
```

### Example
```
GOOD ENOUGH × Metric Coffee: Selvedge Apron. West Loop Market this Saturday only. Waxed canvas with leather trim. Limited edition of 25.
```

### Market Cancellation

```
GOOD ENOUGH [MARKET NAME] update: Market canceled this Saturday due to [REASON]. Next drop [DATE]. Contact [PHONE] with questions.
```

### Example
```
GOOD ENOUGH West Loop update: Market canceled this Saturday due to weather. Next drop June 18. Contact 312-555-8000 with questions.
```

### Restock Notification

```
[FIRST NAME], your requested item is available: [PRODUCT] in [COLOR/SIZE]. Available this Saturday at [MARKET NAME]. Reply YES to reserve.
```

### Example
```
Michael, your requested item is available: Pocket Tee in Clay/M. Available this Saturday at West Loop Market. Reply YES to reserve.
```

## CUSTOMER ENGAGEMENT

### Post-Purchase Follow-Up

```
[FIRST NAME], thank you for visiting GOOD ENOUGH at [MARKET NAME]. Activate your NFC tag at goodenough.co/verify for product story and updates.
```

### Example
```
Emma, thank you for visiting GOOD ENOUGH at West Loop Market. Activate your NFC tag at goodenough.co/verify for product story and updates.
```

### NFC Registration Reminder

```
Your GOOD ENOUGH [PRODUCT] is waiting to be authenticated. Tap NFC tag with phone or visit goodenough.co/verify and enter code [CODE].
```

### Example
```
Your GOOD ENOUGH Canvas Tote is waiting to be authenticated. Tap NFC tag with phone or visit goodenough.co/verify and enter code CH-2845.
```

### Limited Availability Alert

```
[FIRST NAME], your [PRODUCT] in [SIZE] is being held at GOOD ENOUGH [MARKET NAME] until 11am this Saturday. Reply CONFIRM to secure.
```

### Example
```
James, your Canvas Work Pants in 32 are being held at GOOD ENOUGH West Loop until 11am this Saturday. Reply CONFIRM to secure.
```

## TECHNICAL DETAILS

### Character Count Guidelines

| Message Type | Optimal Length | Maximum Length |
|:---|:---|:---|
| Weekly Drop | 120-140 chars | 160 chars |
| Special Announcements | 140-160 chars | 180 chars (2 parts) |
| Customer Engagement | 130-150 chars | 160 chars |
| Seasonal | 130-150 chars | 160 chars |
| Loyalty Program | 140-160 chars | 180 chars (2 parts) |

### Sending Schedule

| Message Type | Timing | Frequency |
|:---|:---|:---|
| Weekly Drop | Friday, 6:00pm | Weekly |
| Restock Notification | Thursday, 5:00pm | As needed |
| Post-Purchase | Sunday, 12:00pm | Weekly |
| NFC Reminder | Tuesday, 5:00pm | 3 days after purchase |
| Loyalty Program | Wednesday, 5:00pm | Monthly |

### Opt-Out Management

All subscribers must have the ability to opt out of messages. Include "Reply STOP to unsubscribe" in initial messages and ensure the SMS platform is configured to automatically process STOP, CANCEL, UNSUBSCRIBE, QUIT, and END commands.
