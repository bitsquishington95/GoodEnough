## Module 2 · Sales Training Manual

### 2.1 Booth Script Framework
1. **Welcome:** "Morning! Everything you see is locally made here in the city—tap the tag to prove it."
2. **Story Bite:** 15‑second brand origin + city capsule hook.
3. **Fit & Feel:** Encourage try‑on, highlight fabric weight.
4. **Upsell:** Suggest complementary SKU (e.g., tote) or limited capsule preorder.
5. **Close:** "We take any card or tap—your purchase helps keep local manufacturing alive."

### 2.2 Upsell Techniques
- Bundle discount when buying tee + tote
- Limited‑run enamel pin at checkout screen
- "Tap for Secret" NFC link reveals preorder list for next capsule

### 2.3 Daily Routine
- 10‑min opening huddle: yesterday's KPIs, today's target
- Mid‑shift micro‑clean + restock every 90 min
- End‑of‑day cash‑up & inventory delta log

### 2.4 KPI Tracker (minimum fields)
| Metric | Target | Notes |
| -- | -- | -- |
| Booth converts | ≥ 22 % | (# of paying customers ÷ booth visitors) |
| AOV | $68 | Monitor effect of bundle offers |
| NFC taps: sales ratio | 3 : 1 | Every 3 taps should land 1 sale |
| Return rate | < 3 % | Monitor size exchanges |

### 2.5 NFC Authentication Demo Playbook  

**Purpose** Show customers the quiet-luxury proof behind every GOOD ENOUGH™ piece.  

1. **Gear Checklist**  
   • iPad or NFC-enabled phone (brand-supplied app pre-loaded)  
   • One tagged garment in demo drawer (ideally current capsule hero)  
   • Portable battery pack (no dead devices mid-demo)

2. **30-Second Demo Script**  
   "Tap right here—see how the tag opens? That's your one-of-one certificate: city, batch, and care notes. It's how we keep knock-offs out of farmers markets."  
   • Keep the phone in the customer's hand; the physical gesture boosts memory.  
   • Pause while the page loads; let them scroll themselves.

3. **Upsell Hooks**  
   • "Each city's tag unlocks different stories and rewards—collect a few and the app starts connecting them."  
   • "Online restocks sell out faster because NFC buyers get early alerts; grab it here and you're already on the inside."

4. **Practice Drill for Staff** (daily open)  
   • 10 rapid-fire taps + script run-throughs before market opens.  
   • Rotate garments so every style's copy stays fresh.

5. **Troubleshooting**  
   • If tag won't read, clean phone sensor, then garment tag.  
   • Still failing? Swap to backup demo piece and log the tag ID for QC.

## Module 4 · Troubleshooting Guide

### 4.1 Tech
| Issue | Quick Fix | Escalate To |
| -- | -- | -- |
| POS offline | Hotspot on phone; reboot iPad | HQ if >15 min |
| NFC tag dead | Swap spare tag; update SKU link | Digital lead |

### 4.2 Weather
- **High wind:** Add 25 lb sandbags to each leg; drop back wall.
- **Rain:** Deploy clear sidewalls; move inventory off ground.
- **Extreme heat:** Provide misting bottle & shade cloth.

### 4.3 Customer Service
| Scenario | Response Line |
| -- | -- |
| Sizing complaint | "Happy to exchange here or online—keep tags on." |
| Price pushback | Explain local manufacturing & limited run value |
| Defect claim | Document with photo, issue replacement, log in QC sheet |

### 4.4 Dealing with Competing Vendors & Market Placement

1. **Pre-Market Recon**  
   • Map vendor list; identify any direct apparel overlap.  
   • Note traffic flow patterns from past weekends (entry points, food stalls).

2. **Booth Position Tactics**  
   • If placed beside high-energy vendors (live music, kids' crafts) lean into minimalist calm—extra floor space, low-volume ambient.  
   • If buried mid-row, set "breadcrumb" signage at row ends: **skull emoji + arrow + NFC tap icon**.

3. **Differentiation Levers**  
   • Real-time NFC demos (see Module 2 addition)  
   • 'Try-on station' with mirror + subtle scent diffuser (signature cedar)  
   • "Local Capsule Only Here" chalkboard to signal scarcity.

4. **Negotiating Placement** (with market manager)  
   • Offer early load-in volunteer help; gain goodwill for future slot swaps.  
   • Present sales data showing your booth boosts adjacent vendors' dwell time.

5. **Conflict / Crowding Scenarios**  
   • If next-door vendor encroaches: mark territory lines with tape first, politely cite fire-lane rules if needed.  
   • For under-pricing copycat tees: educate customers via NFC story ("verified vs. prints"). Do **not** engage vendor publicly—maintain luxury composure.

### 5.4 Regional Capsule Forecast & Re-Order Framework

1. **Baseline Formula**  
   ```
   Opening Order = (Forecasted foot-traffic × Expected conversion rate) ×
                   (Avg units per sale) × (Launch promo factor 1.2)
   ```
   • Use farmers-market foot-traffic reports or licencee past totals.  
   • Launch promo factor cushions first-drop hype.

2. **Size Curve Template** (unisex tee example, adjust per region)  
   XS 5 %  |  S 18 %  |  M 32 %  |  L 28 %  |  XL 12 %  |  XXL 5 %

3. **Colorway Allocation**  
   • Core neutral (e.g., Bone) → 60 %  
   • City accent color → 30 %  
   • Limited "secret" variant (announce via NFC push) → 10 %

4. **Re-Order Triggers**  
   • Automatic notification when any SKU hits **35 %** of opening units.  
   • Lead time cheat-sheet in Airtable:  
     – Local cut-and-sew: 10 days  
     – Dye-house over-dye: +4 days  
     – Tag + QC: +2 days

5. **Seasonality & Events Overlay**  
   • Add 20 % buffer four weeks before major local festivals or university move-ins.  
   • For off-season markets (winter indoor), shift mix toward heavyweight fleece and accessory SKUs; recalculate size curve accordingly.

6. **Quick-View Order Calendar**  
   • Week 0: Submit opening PO  
   • Week 3: First inventory audit & re-order if ≤35 % remaining  
   • Week 6: Capsule refresh decision point (new accent, collab drop)  
   • Week 10: Clearance plan or roll-over to outlet channel
